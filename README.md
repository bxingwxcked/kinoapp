# kinoapp
Kinoapp — это современное мобильное приложение на Flutter, предназначенное для удобного просмотра каталога фильмов и управления личной коллекцией. Авторы приложения Эльцер Данила и Жудинов Данил. Приложение поддерживает динамическую смену тем (светлая/темная), кастомизацию цветовой схемы через Material 3 и включает в себя функционал корзины и детальных страниц для каждой кинокартины. Интерфейс оптимизирован для комфортного использования благодаря шрифту Manrope и продуманной навигации.
